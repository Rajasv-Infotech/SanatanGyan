# External text-reading sources used in v0.8

The app does not copy copyrighted modern translations. It opens public online repositories in the system browser.

Curated direct read-online links are included for major texts where a stable public edition was verified, including:
- Rigveda — Sacred Texts
- Samaveda — Sacred Texts
- Yajurveda — Sacred Texts
- Atharvaveda — Sacred Texts
- Valmiki Ramayana — Sacred Texts
- Mahabharata — Sacred Texts
- Bhagavad Gita — Sacred Texts
- selected principal Upanishads via Sacred Books of the East / Sacred Texts
- Patanjali Yoga Sutras — Sacred Texts
- Hatha Yoga Pradipika — Sacred Texts
- Manusmriti / Laws of Manu — Sacred Texts
- Vishnu Purana — Sacred Texts

Every one of the 136 catalog entries also contains a title-scoped Internet Archive link so the user can inspect digitized public copies and editions.

External editions can differ by recension, translator, commentary and publisher. The app therefore asks readers to note edition metadata before quoting a passage.
